2026–2027 学年上海市部分市重点中学高一上**周练 / 周末作业**的 LaTeX 重排版。

原始材料来自微信公众号图文——试卷以 PNG 图片形式发布（无文字层），本目录内容已逐题 OCR
重排为可编辑的 XeLaTeX 源码，并**按「试卷 / 答案」分离输出**：
试卷版只有题目，答案版才含答案与解析。

其中 `高一10` 一份的原始材料不是公众号图文，而是家长拍摄的学生作业**照片**（卷面含学生
作答与教师红笔批改）。该份试卷版照原卷录入试题文字，答案版给出的是**正确解答与解析**
（学生答错、教师红笔改正处一律按正确结果给出），差异见文末「说明」。

## 答案与试卷如何分离

`源码/common.sty` 里用一个条件开关控制答案内容的显隐：

```latex
\newif\ifanswer
\ifdefined\isanswer\answertrue\fi
\newcommand{\ans}[1]{\ifanswer …输出【答案】…#1…\fi}
```

- **试卷版**：不传入 `\isanswer`，`\ans{}` 及其后的解析块整段不输出。
- **答案版**：编译时传入 `\def\isanswer{1}`，答案与解析正常渲染。

题目本身在两种版本中完全一致，因此答案版也同时是一份"带解析的讲解稿"。

## 答案版为什么这样排

解析原本是一条几百字的连续段落，读者看不出解题分几步。答案版做了两处统一处理：

1. **解析分步**——一条解析在顶层分隔符（`；`、句末句点）处切成若干「步骤」，
   每步独占一段，段间留 0.16em 呼吸空间，行首挂一枚浅灰蓝小方块；
   以 `(1)(2)①` 开头的步骤另用 `\stepm{标号}{正文}`，标号加粗着色、正文悬挂对齐。

   ```latex
   \solbegin
   \step{由题意得 $a+2=-1$，解得 $a=-3$.}
   \stepm{(2)}{因为 $B=\{-2,2\}$，所以 $a+2=-2$.}
   \solend
   ```

2. **标签悬挂缩进**——【答案】【解析】用深钢蓝加粗贴在段首，正文整体右移一档，
   换行时与正文左端对齐，标签不会和正文糊在一起。

另外，选择题的 `\ans{...}` 在答案版中一律排在**整段选项之后**，
使答案稿按「题目 → 选项 → 答案 → 解析」的顺序阅读（原稿中答案位置不一，
有写在选项之前的，也有夹在 A 与 B 之间的）。

切步只动排版命令，**不增删任何一个字**：脚本会校验切分前后去掉空白后逐字相同。

## 编译方式

在 `源码/` 目录（或 `papers/` 目录）下执行：

```bash
make            # 编译全部：试卷版 -> ../试卷/，答案版 -> ../答案/
make test       # 只编试卷版
make ans        # 只编答案版
make one F=高一02_大同中学_集合综合练习    # 只编某一套
make check      # 校验试卷版确实不含答案（逐份文本比对）
make list       # 查看页数统计
make clean      # 清理 LaTeX 临时文件
```

需 `xelatex`（TeX Live / MacTeX 均可）、`pdfinfo` 与 `pdftotext`（poppler）。
`make check` 会抽取两版 PDF 的文本，确认试卷版中【答案】【解析】标记数为 0、答案版大于 0。

## 说明

- 原卷为微信公众号图片，答案以原卷给出的版本为准，未擅自改动。
- 试卷中出现的插图直接取自原卷截图（如格致中学第 4 题的 Venn 图，`源码/figures/`），
  **不用 TikZ 重绘**，以保证与原卷完全一致。
- **解答题作答题区**：OCR 重排会丢掉原卷给解答题留的书写空间，故由 `\ansspace[n]` 按题量
  重新留白（2 小问约 5–6 行、3 小问约 7–8 行、含证明/压轴 8–10 行、5 小问 10–12 行，行高 1.2cm）。
  留白只在**试卷版**输出，答案版不输出作答题区。
- **答案版排版**：解析统一改成分步版式（详见上节），因此答案版页数比试卷版多。
  高一06 原卷只给答案、没有解析，其「参考答案」本就是一行一子题的列表，无需再切步。

### 高一10（周中小练习1）专记

这一份的原始材料是**家长拍摄的学生作业照片**（卷面得分 62 分，含学生铅笔/蓝笔作答与教师
红笔批改），不是公众号印好的试卷，故有两处与前 8 份不同：

1. **答案口径**——照片上的「答案」其实是学生本人的作答，正确与否不一；本稿答案版一律给出
   **经核验的正确结果**。学生答错、教师红笔改正的位置如下（左＝学生原答，右＝本稿答案）：

   | 题号 | 学生原答 | 正确结果 |
   |------|---------|---------|
   | 填空 3 | $(-1,+\infty)$ | $(-1,1)\cup(1,+\infty)$ |
   | 填空 7 | $(-\infty,2)$ | $(-\infty,0]$ |
   | 填空 8 | $(-\infty,6]\cup(9,+\infty)$ | $(-\infty,6)\cup(9,+\infty)$ |
   | 填空 9 | $0$ 或 $\dfrac{9}{16}$ | $0$ 或 $-\dfrac{9}{16}$ |
   | 填空 10 | $\dfrac{1}{2}$ | $4$ |
   | 选择 12 | C | B |
   | 选择 13 | C | A |
   | 解答 15(2) | 6056 | 6055 |

   第 13 题、第 15(2) 题的正确结果已用程序穷举全部情形复核（13 题：$X_1+X_2+X_3$ 可取
   $39\sim57$ 的每一个整数，故 37 不可能；15(2)：$a_1+a_2+a_3$ 最大为
   $2015+2019+2021=6055$）。
2. **页首笔误**——原卷印作「（1-6 题 5 分，**8-10** 题 8 分）」，与第 7 题的实际情形不符，
   疑为「7-10 题 8 分」之误；本稿照原卷抄录，未擅改（源码内有 `%` 注说明）。

另外，第 15(2) 题解析中「10 个和依次为 4030, 4034, …」一行，数字列表在行内数学里是
**不可断行**的整体，实测撑出右边距 184pt 且被页面裁掉、肉眼几乎看不出。已按
`$4030,\allowbreak 4034,\allowbreak …$` 逐一插入断行点解决。
