# 试卷与答案 · 高一上数学

2026–2027 学年上海市部分市重点中学高一上**周练 / 周末作业**的 LaTeX 重排版。

原始材料来自微信公众号图文——试卷以 PNG 图片形式发布（无文字层），本目录内容已逐题 OCR
重排为可编辑的 XeLaTeX 源码，并**按「试卷 / 答案」分离输出**：
试卷版只有题目，答案版才含答案与解析。

翻拍照片**（卷面为**学生本人的手写作答**；`高一10` 还叠着教师用**蓝笔**写出的订正与用
**红笔**打的 ✓/×、卷面总分）。这三份的试卷版照原卷录入试题文字，答案版给出的是**经核验
的正确解答与解析**（学生答错处一律按正确结果给出），逐题差异见文末「说明」。

`高一13` 的原文虽是公众号图文，但**本身就是一份「讲评版」**——题目下方直接印出【答案】
或【解析】。本稿把原卷印在行间的答案与解析全部移到答案版，题目文字一字未动，因此这一份
的试卷版是一张**干净的空卷**，答案版则是原卷的讲评内容（分步重排）。

## 题目溯源

### 核对摘要

| 项 | 结果 |
|------|------|
| 核对范围 | 12 份试卷的 **211 道**一级题干，逐题比对参考库的 **16,180 道**高考真题 |
| 定到具体高考试卷 | **16 道**（原题照录 7、改编 8、借定义另出题 1；其中 高一10 第 4 题 与 高一11 第 7 题 是同一道，故实占 17 个题位） |
| 跨卷同题（校际重复） | **7 组**，已逐条核对成员（其中 2 组是同模板带变体，5 组题干逐字相同） |
| 与真题同题型但非同一题 | 约 30 道，逐条判读过，未计入 |
| 其余 | 真题库里既无 ≥12 字的逐字串、也无 ≥0.72 的整段相似度 → 非高考真题 |

本轮核对**发现并订正了 4 处**（都是核对过程本身查出来的，不是新发现而是纠错）：

1. **转录错误**：高一08 第 15 题（1999 广东卷 Venn 图题）选项 A 误录为 $(M\cap P)\setminus S$，
   原卷是 $(M\cap P)\cap S$ —— 已改源码并重编两版。
2. **判定写错**：高一10 第 11 题原判「改编（有序对→差集）」，但真题本身就是差集
   $B=\{x-y\mid x,y\in A\}$，应判**原题照录**（差别只在四个选项的次序被倒过来）。
3. **描述不实**：高一10 第 2 题原写「$U$ 少一个元素，问法改变」，实际问法未变，只是
   $U$ 由 $\{0,\dots,9\}$ 改成 $\{0,\dots,8\}$（答案随之由 $\{7,9\}$ 变为 $\{7\}$）。
4. **题号与计数**：三处题号（高一03、高一09、高一12）先前按 `\item` 出现次序编号，
   与卷面的 `\setcounter{enumi}` 口径不符，已订正；「一级题干 230 道」「真题 15,932 道」
   两个数字同属口径错误，已改为 **211** / **16,180**。

### 上游是「共享题库」：7 组跨卷同题

把 12 份试卷的 **211 道**一级题干抽出来两两交叉比对（判据：脱去 LaTeX 与标点后的骨架文本

| 题目 | 份数 | 分布 |
|------|:---:|------|

| $f(x)=\dfrac1{1-x}$ 迭代（$x\in A\Rightarrow\dfrac1{1-x}\in A$） | 2 | 03 第 18 题、12 第 19 题 |

七组成员逐条核对过（成员题号按卷面编号、题干逐字比对）：**前两组只是同模板**——成员之间有
数字或措辞差异、答案也随之不同；**其余五组题干逐字相同**，最多差一个引导词（如「设集合」与
「已知集合」）或一处括注写法。

判据放宽（改用 3-gram Jaccard + 序列相似度，不要求长逐字串）还能多出若干组，但那些多是
**同模板换数字**（如 $A=\{x\mid x^2-3x+2=0\}$ 与 $A=\{x\mid x^2+4x=0\}$ 两个版本），证据强度
不及上表，故不计入；同类的还有共享同一自定义概念但问法不同的（如 高一07 与 高一10 的「特征数」）。

不同学校、不同周次出现这么多同题，说明各校备课组**大量取材于同一批公共题源**（教辅、网络
题库、区统考、教材习题），而非各校独立原创。旁证是这些题在菁优网、1010jiajiao、百度题库、
作业帮上都能搜到近乎一致的版本。

### 考据不出来的：绝大多数

把 12 份试卷里的**自定义名词**逐个在全库检索：

- **全库皆无**：闭集合、和谐集、好集、划分集、互斥子集、可积数集、二分划、三数循环、
  全食／偏食、高斯函数；
- **同名不同题**：「封闭集」见于 2010 四川卷（文/理；定义是 $x+y,\ x-y,\ xy\in S$），而
  高一05 用的是「$a_i+a_j$ 与 $a_j-a_i$ 至少有一个属于 $M$」——**借名不借题**；「特征数」
  见于 2013 湖南卷（文）与 1977 江苏常州卷（前者的指子集的 0/1 指示数列，后者的含义与之
  也不同），与 高一07／高一10 的「最大最小之差／之和」**同名不同义**。

也就是说，这些「新定义压轴题」**都不是高考真题**，应属校本自编，或取材自模考／竞赛／自招
与教辅。

### 方法与局限

- 方法：把题目脱去 LaTeX 与标点做「骨架」文本 → 6-gram 倒排索引全召回 → 最长公共子串 +
  整段相似度判定 → 人工复核高置信项。**两个判据要一起看**：长题靠「最长公共子串 ≥ 12」，
  短题（如一句式的选择题）最长串天然长不了，靠「整段相似度 ≥ 0.72」补上。上表 16 道里，
  高一08 第 11 题、高一10 第 4 题与 高一11 第 7 题、高一03 第 12 题 都是只靠后者才捞出来的。
- **两个曾导致漏检的口径陷阱**（已修，记此备查）：① 两边必须用**同一套**归一化——参考库
  那侧若只做骨架化、不先剥 LaTeX 命令，`\operatorname{card}` 会留下 `operatornamecard`
  这类残渣，与已经剥干净的高一文本对不上，实测把同一道题的相似度从 38 压到 12；
  ② 预筛不能用「共享片段数 top-K」截断，候选一多真匹配就会被挤出榜外。
- **题号口径**：一律按**卷面实际编号**（源码里靠 `\setcounter{enumi}` 还原，与 `\item` 的
  先后顺序不同）；比对前会把参考库里个别「答案/解析被误排进 `problem` 块」的条目先截断，
  否则会压低整段的相似度而漏检。
- **局限 1**：参考库只含**高考真题**，不含模考、竞赛与教材习题，所以「检索不到」只能说明
  「不是高考真题」，**不能据此推断为自编**。

## 答案与试卷如何分离

`源码/common.sty` 里用一个条件开关控制答案内容的显隐：

```latex
\newif\ifanswer
\ifdefined\isanswer\answertrue\fi
\newcommand{\ans}[1]{\ifanswer …输出【答案】…#1…\fi}
```

- **试卷版**：不传入 `\isanswer`，`\ans{}` 及其后的解析块整段不输出。
- **答案版**：编译时传入 `\def\isanswer{1}`，答案与解析正常渲染。

题目本身在两种版本中完全一致，因此答案版也同时是一份"带解析的讲解稿"。

## 答案版为什么这样排

解析原本是一条几百字的连续段落，读者看不出解题分几步。答案版做了两处统一处理：

1. **解析分步**——一条解析在顶层分隔符（`；`、句末句点）处切成若干「步骤」，
   每步独占一段，段间留 0.16em 呼吸空间，行首挂一枚浅灰蓝小方块；
   以 `(1)(2)①` 开头的步骤另用 `\stepm{标号}{正文}`，标号加粗着色、正文悬挂对齐。

   ```latex
   \solbegin
   \step{由题意得 $a+2=-1$，解得 $a=-3$.}
   \stepm{(2)}{因为 $B=\{-2,2\}$，所以 $a+2=-2$.}
   \solend
   ```

2. **标签悬挂缩进**——【答案】【解析】用深钢蓝加粗贴在段首，正文整体右移一档，
   换行时与正文左端对齐，标签不会和正文糊在一起。

另外，`\ans{...}` 在答案版中还统一了两件事：一是选择题的答案一律排在**整段选项之后**，
使答案稿按「题目 → 选项 → 答案 → 解析」的顺序阅读（原稿中答案位置不一，有写在选项之前的，
也有夹在 A 与 B 之间的）；二是 `\ans{}` 里多小问题的**子题编号一律用全角**「（1）（2）（3）」，
编号与紧随其后的答案之间不留空格（全角括号自带边距）。全稿 12 份口径一致。

后一条只作用于 `\ans{}`：题干里的子问标号（`enumerate` 的 `label=(\arabic*)`）与解析里的
`\stepm{(1)}{…}` 仍保持半角，即同一份答案稿中【答案】行的子题编号为全角、题干与解析中的
子问标号为半角。两类标号分处答案与过程，不必强求一致。

切步只动排版命令，**不增删任何一个字**：脚本会校验切分前后去掉空白后逐字相同。

## 编译方式

在 `源码/` 目录（或 `papers/` 目录）下执行：

```bash
make            # 编译全部：试卷版 -> ../试卷/，答案版 -> ../答案/
make test       # 只编试卷版
make ans        # 只编答案版
make one F=高一02_大同中学_集合综合练习    # 只编某一套
make check      # 校验试卷版确实不含答案（逐份文本比对）
make list       # 查看页数统计
make clean      # 清理 LaTeX 临时文件
```

需 `xelatex`（TeX Live / MacTeX 均可）、`pdfinfo` 与 `pdftotext`（poppler）。
`make check` 会抽取两版 PDF 的文本，确认试卷版中【答案】【解析】标记数为 0、答案版大于 0。

**编译时附带缺字检查。** `xelatex` 遇到字体里没有的字形时，只往日志写一行
`Missing character: There is no ★ (U+2605) in font …` 就继续编译，该字符被**静默丢弃**——
PDF 里直接消失，不留空白、也不报错。所以 `make test` / `make ans` / `make one` 在每条编完会
立即扫日志，命中就中止本次构建并点名是哪个字符：

```
❌ 高一04_位育中学_周末作业1 有字符没字形（PDF 里已静默消失）：★ (U+2605)
   处理：把该字符划入 CJK 字符类（见 common.sty 的 xeCJKDeclareCharClass）
```

往题里加新符号（★、℃、生僻字等）时，先照 `common.sty` 里 `\xeCJKDeclareCharClass` 的写法
把对应码位划入 CJK 类——圈数字 `①②③` 就是这么处理的（现用了 293 次、遍布 11 份）。

**第 14 题**：$A$ 与 $B$ 都是 $\pi$ 的奇数倍构成的集合（$4n+1$ 与 $4n-1$ 合起来正好跑遍
所有奇数），所以 $A=B$，学生所选的「$B\subset A$」不对。

**第 17(2) 题**：学生把 $B=\{-2\}$ 这一情形判成「舍」。原因是列方程时把两根之积写成了
$2a-4=-4$（应为 $2a-4=(-2)\times(-2)=4$），于是与由两根之和得出的 $a=4$ 对不上而误排除。
正确结果是 $a=1$ 或 $a=4$；又判别式 $\Delta=(a-4)^2\geqslant 0$ 恒成立，$B$ 不可能为空集，
故本题无需讨论 $B=\varnothing$。

**第 11 题的答案取 $5$**：把「$a,b$ 都要选出」理解为 $a,b$ 都属于所选的两个子集，则含 $a,b$ 的
子集只有 $\{a,b\}$、$\{a,b,c\}$、$\{a,b,d\}$、$\{a,b,c,d\}$ 四个，其中可比（一个包含另一个）的
共 5 组：$\{a,b\}\subset\{a,b,c\}$、$\{a,b\}\subset\{a,b,d\}$、$\{a,b\}\subset\{a,b,c,d\}$、
$\{a,b,c\}\subset\{a,b,c,d\}$、$\{a,b,d\}\subset\{a,b,c,d\}$。「选出 2 个子集」的选法**不计先后**，
$A\subseteq B$ 与 $B\subseteq A$ 说的是同一组子集，所以是 $5$ 而不是 $5\times2$。

本题系 2010 年上海高考理科第 14 题的改写（原题要求选出 **4** 个子集、且 $\varnothing$ 与 $U$
都要选出）。原题官方答案是 **36**，其官方解答明言「$A$ 和 $B$ 可以互换，即视为一种选法」，
即按**不计先后**计数——本仓库已用穷举复核：$\{\varnothing,S_1,S_2,U\}$ 且两两可比的 4 子集恰有
36 个（若把中间的 $S_1$、$S_2$ 计先后则为 72）。按同一口径，本改写题应取 $5$。
原卷作答处是学生手写的 $10$（有改写的痕迹），网上流传的同题解答也写作 $10$
（把 $A\subseteq B$ 与 $B\subseteq A$ 当成两种选法），属重复计数。

**第 21 题（附加）有两组解**：六个乘积中恰有 4 个负值，说明 4 个数中恰有 2 正 2 负；由
$(a_1a_2a_3a_4)^3=(-24)(-2)\left(-\frac32\right)\left(-\frac18\right)\times1\times3=27$ 得
$a_1a_2a_3a_4=3$，去符号后四数的绝对值只能是 $\left\{4,\dfrac14,6,\dfrac12\right\}$。其中
$\left\{4,\dfrac14\right\}$ 相乘得 $1$、$\left\{6,\dfrac12\right\}$ 相乘得 $3$，恰是两组同号数；
两组异号时即得两组解：$4,\dfrac14,-6,-\dfrac12$（和为 $-\dfrac94$）与
$6,\dfrac12,-4,-\dfrac14$（和为 $\dfrac94$），**两组都满足原卷所给的乘积集合**，
故本稿答案写作 $\pm\dfrac94$。

**第 5 题用 $\subset$（真包含）**——原卷印的符号**没有下划线**，与同一份卷子里第 9、13 题
带下划线的 $\subseteq$ 在卷面上明显不同（已逐处放大比对确认），故按「真子集」口径解答：
$B$ 是 $(x-1)(x-a)\leqslant 0$ 的解集，当 $a>1$ 时 $B=[1,a]$、$a<1$ 时 $B=[a,1]$，
由 $[1,2]\subsetneq B$ 得 $a>2$，答案 $(2,+\infty)$（若误按 $\subseteq$ 读则会得到 $a\geqslant 2$，
与原卷所印符号不符）。

**第 11 题**（「全食 / 偏食」）是原卷自造的两个名词：一个集合是另一个的子集叫「全食」，
有公共元素但互不为子集叫「偏食」。$A=\left\{-1,\dfrac12,1\right\}$，$B=\{x\mid ax^2=1,\ a\geqslant 0\}$：
$a=0$ 时 $B=\varnothing\subseteq A$（全食）；$a>0$ 时 $B=\{-t,t\}$（$t=1/\sqrt a$），$t=1$ 即
$a=1$ 时 $B=\{-1,1\}\subseteq A$（全食），$t=\dfrac12$ 即 $a=4$ 时 $A\cap B=\left\{\dfrac12\right\}$
且互不包含（偏食）。故 $a=0$ 或 $1$ 或 $4$。

**第 12 题**是计数题：在 $U=\{1,2,\cdots,10\}$ 的所有二分划 $(A,B)$（$A,B$ 非空、不交、
并为 $U$）中，要求 $x\in A\Rightarrow x+1\in B$，求分划数。由条件可知 $A$ 中不含相邻两数，
且 $10\notin A$（否则需 $11\in B$，而 $11\notin U$），于是化为在 $\{1,\cdots,9\}$ 中数
**不含相邻元素**的非空子集个数：斐波那契数 $f(9)=89$ 减去空集的那一种，得 $88$。
本仓库已用程序穷举全部 $2^{10}$ 种分划复核（结果 $88$，与斐波那契口径一致）。

**第 15、16 题也经程序穷举复核**：第 15 题对 $a$ 扫描全轴得 $a\in[-1,0)\cup(2,3]$；
第 16 题对 $P=\{1,2,3,4,5\}$ 的全部非空子集对计数得 $49$（按 $k=\max A$ 分类求和
$15+14+12+8=49$）。

而不触发条件，若按字面理解会出现 $A=\{0,1\}$ 这样的双元素反例；本稿按常规理解（$A$ 的元素
