# 数学 (Mathematics)

## 本目录用途
收录日常练习/考试中的错题与对应薄弱知识点，用于复盘与针对性复习。

## 内容结构
- `mistakes/`   错题条目。现有数学错题集 1 份：`赵文瀚-数学错题集1-20260925`（16 题，题干 + 按来源分组 + 每题一个手写填空栏，4 页；同目录另有源 PDF 的归档副本 `…_原卷.pdf`）。命名规范与编译见下节
- `weakpoints/` 薄弱知识点汇总（从错题提炼）
- `review/`     复习计划与复盘记录
- `papers/`     试卷与答案（LaTeX 重排版，试卷版 / 答案版分离，见 `papers/README.md`）

## 单条错题建议字段
- 日期、来源（作业/月考/模拟/高考真题）
- 题目（可附文本或截图）
- 我的错答 / 正确答案
- 错误原因（概念不清/计算失误/审题/方法不当）
- 关联知识点标签
- 掌握程度（0–5）

## 知识模块（便于打标签）
集合与常用逻辑用语、函数与导数、三角函数、数列、立体几何、解析几何、概率统计、不等式、向量

> `papers/` 里已入库的 41 套卷子都属这一模块（卷面副标题多数即「集合与常用逻辑用语」，
> 高一14 照原卷作「集合与逻辑单元练习」、高一24 照原卷作「集合与逻辑、等式的性质」）。
> 「套」的算法见 `papers/README.md`「试卷清单」：43 个 `.tex` 里 `高一16`≡`高一b`、`高一18`≡`高一c`，
> 一套副本只算一套，故 41。

## 命名规范与编译方式（`mistakes/`）

**命名规范**：`赵文瀚-数学错题集N-YYYYMMDD.tex`（编译产物为同名 `.pdf`）

- `赵文瀚-`：固定前缀，即学生姓名（与卷面、导出件一致）；
- `N`：**卷次**，从 1 起；同一导出件里若含多辑就依次编号；
- `YYYYMMDD`：**源件的日期**（照源件标题行里那个日期，不写编译日）——现有这份即
  `赵文瀚-数学错题集1-20260925`，源件标题行是「赵文瀚-数学错题集-20260925」；
- 源件的**原样副本**归档为「主干 `_原卷` + 原扩展名」：`赵文瀚-数学错题集N-YYYYMMDD_原卷.pdf`
  （沿用 `English/mistakes` 的惯例；**不参与编译**，`make clean`／`distclean` 都不会删它），
  便于日后回原卷复核转录。

**编译方式**：

```bash
cd mistakes
make            # 编译 tex → pdf
make check      # 校验：缺字 0 / 题数符合 Makefile 的 WANT_ITEMS / 无答案泄漏 / 页数
make clean      # 清理 LaTeX 临时文件
make distclean  # 清理临时文件与生成的 PDF（`_原卷.pdf` 不动）
make list       # 查看产物页数与原卷件数
make help       # 显示上面这份说明
```

**可复现构建**：源码不变时重编得到**逐字节相同**的 PDF，故 git 里「重编一遍」不会产生无意义的
二进制 diff（做法与原理同 `English/mistakes`：`SOURCE_DATE_EPOCH` + `latexmk -usepretex` 注入
docinfo；细节见 `mistakes/Makefile` 头部注释）。实测连续两轮 `make distclean && make` 的 md5 相同。

错题集正文本式：每题 = 题干 + 一个「手写填空栏」，后者字段即上面「单条错题建议字段」
（我的错答／正确答案／错误原因／知识点标签／掌握度 0–5），供打印后手写。
