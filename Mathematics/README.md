# 数学 (Mathematics)

## 本目录用途
收录日常练习/考试中的错题与对应薄弱知识点，用于复盘与针对性复习。

## 内容结构
- `mistakes/`   错题条目（按日期或知识点命名）
- `weakpoints/` 薄弱知识点汇总（从错题提炼）
- `review/`     复习计划与复盘记录
- `papers/`     试卷与答案（LaTeX 重排版，试卷版 / 答案版分离，见 `papers/README.md`）

## 单条错题建议字段
- 日期、来源（作业/月考/模拟/高考真题）
- 题目（可附文本或截图）
- 我的错答 / 正确答案
- 错误原因（概念不清/计算失误/审题/方法不当）
- 关联知识点标签
- 掌握程度（0–5）

## 知识模块（便于打标签）
集合与常用逻辑用语、函数与导数、三角函数、数列、立体几何、解析几何、概率统计、不等式、向量

> `papers/` 里已入库的 28 套卷子都属这一模块（卷面副标题多数即「集合与常用逻辑用语」，
> 高一14 照原卷作「集合与逻辑单元练习」、高一24 照原卷作「集合与逻辑、等式的性质」）。
> 「套」的算法见 `papers/README.md`「试卷清单」：30 个 `.tex` 里 `高一16`≡`高一b`、`高一18`≡`高一c`，
> 一套副本只算一套，故 28。
