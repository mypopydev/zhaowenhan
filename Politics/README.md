# 政治 (Politics)

## 本目录用途
收录日常练习/考试中的错题与对应薄弱知识点，用于复盘与针对性复习。

## 内容结构
- `mistakes/`   错题条目（按日期或知识点命名）
- `weakpoints/` 薄弱知识点汇总（从错题提炼）
- `review/`     复习计划与复盘记录

## 单条错题建议字段
- 日期、来源（作业/月考/模拟/高考真题）
- 题目（可附文本或截图）
- 我的错答 / 正确答案
- 错误原因（术语不准/材料误读/知识混淆/表述）
- 关联知识点标签
- 掌握程度（0–5）

## 知识模块（便于打标签）
经济生活、政治生活、文化生活、生活与哲学、选择性必修、时事热点
