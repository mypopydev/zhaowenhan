# 物理 (Physics)

## 本目录用途
收录日常练习/考试中的错题与对应薄弱知识点，用于复盘与针对性复习。

## 内容结构
- `mistakes/`   错题条目（按日期或知识点命名）
- `weakpoints/` 薄弱知识点汇总（从错题提炼）
- `review/`     复习计划与复盘记录

## 单条错题建议字段
- 日期、来源（作业/月考/模拟/高考真题）
- 题目（可附文本或截图）
- 我的错答 / 正确答案
- 错误原因（模型不清/公式误用/计算/审题）
- 关联知识点标签
- 掌握程度（0–5）

## 知识模块（便于打标签）
力学、曲线运动与万有引力、机械能、动量、电场、磁场、电磁感应、热学、光学、原子物理、实验
