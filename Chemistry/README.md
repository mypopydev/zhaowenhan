# 化学 (Chemistry)

## 本目录用途
收录日常练习/考试中的错题与对应薄弱知识点，用于复盘与针对性复习。

## 内容结构
- `mistakes/`   错题条目（按日期或知识点命名）
- `weakpoints/` 薄弱知识点汇总（从错题提炼）
- `review/`     复习计划与复盘记录
- `papers/`     试卷与答案（LaTeX 重排版，试卷版 / 答案版分离，见 `papers/README.md`）

## 单条错题建议字段
- 日期、来源（作业/月考/模拟/高考真题）
- 题目（可附文本或截图）
- 我的错答 / 正确答案
- 错误原因（方程式写错/概念混淆/推断失误/实验细节）
- 关联知识点标签
- 掌握程度（0–5）

## 知识模块（便于打标签）
无机元素、有机化学、物质结构、反应原理、电化学、实验、同分异构
