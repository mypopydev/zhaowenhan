2025–2026 学年上海市部分市重点中学高一上**化学月考 / 练习**的 LaTeX 重排版。

原始材料来自微信公众号图文——试卷以 PNG 图片形式发布（无文字层），本目录内容已逐题 OCR

## 答案与试卷如何分离

`源码/chem.sty` 里用一个条件开关控制答案内容的显隐：

```latex
\newif\ifanswer
\ifdefined\isanswer\answertrue\fi
% 卷末「参考答案」整节被 \ifanswer … \fi 包裹
```

- **试卷版**：不传入 `\isanswer`，「参考答案」整节（含 `\newpage`）不输出，页眉无版本标记。
- **答案版**：编译时传入 `\def\isanswer{1}`，参考答案正常渲染，且页眉自动追加【参考答案版】，
  打印后便于与试卷版区分。

题目本身在两种版本中完全一致。

## 编译方式

在 `源码/` 目录（或 `papers/` 目录）下执行：

```bash
make                                     # 编译全部：试卷版 -> ../试卷/，答案版 -> ../答案/
make test                                # 只编试卷版
make ans                                 # 只编答案版
make one F=高一化学_交大附中_10月月考      # 只编这一套
make check                               # 校验试卷版确实不含答案（逐份文本比对）
make list                                # 查看页数统计
make clean                               # 清理 LaTeX 临时文件
```

需 `xelatex`（TeX Live / MacTeX 均可）、`pdfinfo` 与 `pdftotext`（poppler）。
`make check` 会抽取两版 PDF 的文本，确认试卷版中「参考答案」标记数为 0、答案版大于 0。

> `chem.sty` 使用 `ctex` 的 `fontset=mac`，即依赖 macOS 自带中文字体，须在 macOS 上编译。
> 其他平台请把该选项改为本机可用的 fontset。

## 说明

- 原卷为微信公众号图片，个别印刷/笔误已在参考答案中注明，未擅自改动：
  - **第 1 题 (1)** ³He 与 ³H 相同的量：原卷参考答案写作 A（中子数），但两者中子数为 1 与 2、
    质子数为 2 与 1，均不相同，相同的是质量数 3，按题意应为 C。
  - **第 1 题 (5)** 与 Al³⁺ 等电子数的四核微粒：原卷给的是 PH₃，疑为 NH₃ 之误
    （PH₃ 为四核但电子数 18，不满足 10 e⁻；NH₃ 与 CH₄ 均为四核 10 e⁻）。
  - **第 1 题 (6)①** 丰度 $x$、$y$：原卷写作「83.18；13.72」，按给出的相对原子质量与
    平均相对原子质量 28.086 复核，应为 $x=92.18\%$、$y=4.72\%$。
  - **第 3 题 (4)** 气球题：原卷参考答案写作 B，按等质量下 $V \propto 1/\rho$、
    $\rho(\mathrm{CO_2})=1.96$ 最大推算应为 **A**（CO₂ 气球最小）。
- **第 3 题 (5)**（混合气体中甲烷体积与一氧化碳质量）的答案原卷有给（6.72 L；2.8 g），
  早期重排稿遗漏了该条，导致其后 (6)(7)(8) 的答案与题号整体错位一位，已补回并核对。
- 第 3 题气球插图直接取自原卷截图（二值化放大），因原图未印 A/B/C/D 字母，
  按气球中心位置补注，与原卷视觉一致。
