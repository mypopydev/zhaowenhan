# 英语翻译背诵（微信公众号转录）

把微信公众号「发现之旅 速来记单词」《上海高考高分翻译背诵》系列转录为可编辑、
可打印的 LaTeX 卷面。当前收录 **78 期（38–117，2026-07-29 → 10-17）**，缺第 **97、109** 期。
共 346 条译文（另 9 条谚语；第 114 期起文末另附一块「本期词汇」尾块）。单期三版 234 份 +
合册八册三版 24 份，共 **258 份 PDF**。
合册分八册：38–47、48–57、58–67、68–77、78–87、88–98、99–108、110–117。

早期期号（约 38–49）原文是**例句体**：每段形如「N. 英文. 中文」或「中文。英文」，
解析器已能按段内切分；50 期以后为「中文（提示词）+ 英文」两段式。

## 目录约定

| 目录 | 内容 |
|---|---|
| `原文/<期号>.html` | 原文 HTML 的**精简版**：只保留标题、发布时间与正文 `js_content`（平台脚本已剔除，78 篇由 234 MB 降到约 0.30 MB，重解析结果不变） |
| `原文/<期号>.json` | 解析后的条目数据（重排依据，可据此重跑）；可选尾块字段 `proverb`（谚语）、`vocab`（本期词汇）、`note`／条目内 `correction`+`editor_note`（人工补充，见「待办」） |
| `源码/<期号>_zh2en.tex` | 默写卷：中文句 + 提示词，英文留空 → 输出到 `默写/` |
| `源码/<期号>_ans.tex` | 中英对照（背诵 · 答案）→ 输出到 `答案/` |
| `源码/<期号>_en2zh.tex` | 回译卷：英文句，中文留空 → 输出到 `回译/` |
| `工具/抓取解析.py` | 抓取文章页 → `原文/<期号>.html` + `<期号>.json`（限速 2 秒/篇） |
| `工具/生成tex.py` | 由 `原文/*.json` 生成三版 tex 源码（支持 `--bundle N` 合册） |
| `工具/内容校验.py` | 自检：条目完整性、中英配对、提示词、漏条目、tex 是否含该条 |

## 全流程（三步）

```bash
# 1) 取链接：手机微信把文章发到「文件传输助手」→ 扫码 → 自动抽取
node 工具/取链接.js                       # 产出 原文/urls.txt
# 2) 抓取 + 解析：逐篇抓取，产出 原文/<期号>.html 与 <期号>.json
python3 工具/抓取解析.py 原文/urls.txt
# 3) 生成源码并编译（单期）或合册（每 10 期一册）
python3 工具/生成tex.py                   # 单期：每期三版
python3 工具/生成tex.py --bundle 10       # 合册：三版各一册
make && make check
```

## 抓取方式

- 单篇：`curl` 带浏览器 UA 直取文章页（HTTP 200），正文在 `js_content` 内，
  是**纯文本**（不是图片），解析可靠
- 正文图片为懒加载（`data-src` 由 JS 拼接），本材料的价值在文字，**原图暂不归档**
- 解析规则（已覆盖原文里的几种排版变体）：
  - 过滤前言/尾注类段落（「内容均为手搓…」「手搓原创，感谢支持。」等，不算条目）
  - 中文段（末尾括号为提示词）→ 其后的英文段，成对为一条
  - **一题多译**：连续多段英文都归同一条，首段为正译，其余在答案卷标为「另译」（如第 96 期第 1 题）
  - 谚语三种形态：①英、中各占一段；②同一段内「英文. + 中文」（第 99 期）；③只给中文（第 98 期「开卷有益。」，答案卷注明原文未附英文）
  - 多段英文后紧跟**无提示词**的中文段时，末段英文与该中文判为谚语（否则会串成题目）
  - **推广尾注**：第 112 期起每期文末都有「笔者现已开通知识星球…」一段，按尾注滤掉（与点赞／关注一类同处理）；**第 116 期换了一种**——「另精选优秀市重/SSP高考翻译练习，顶级外刊精练表达，每日更新。」（排在词汇尾块之后），
  同样入 `NOTE_PAT` 滤掉——不滤会把只有 1 组的词汇块挤到倒数第二段、又认不出来
  - **本期词汇**：文末若出现「英文＋短汉字释义」的对照串（第 114 期「-sing solo独唱 smooth out消除
    fast-growing 快速发展的」），判为词汇尾块、存进 `vocab` 字段（不算条目）；生成器在三版末尾排成
    一块「本期词汇」——默写卷只给中文、回译卷只给英文、答案卷给中英对照，占一个题号。
    判认要「至少 2 组」，但**第 115—117 期都只给了 1 组**（115「-sink into their phones 沉迷于手机」、
    116「-half-forgotten 快被遗忘的」、117「-war-torn 战火纷飞的」），故正文**末段**放宽到 1 组（`parse_vocab(..., last=True)`）
- **批量抓取的约束**：公众号没有公开的历史文章列表接口，URL 为随机串，标题里的
  期号无法反推链接；已核实：文内没有指向其他期的链接、文章也**不属于任何合集**。
  `mp.weixin.qq.com` 的登录页是公众号**后台**（需号主管理员扫码），读者登录不了。
  因此批量走「文件传输助手网页版」——你在手机微信里把文章发到文件传输助手，
  `工具/取链接.js` 用 Chrome 打开该网页（你自己的微信扫码登录），自动抽取链接

## 编译

```bash
make          # 编译全部 tex → pdf（落在对应输出目录）
make check    # 校验：每份 1 页、日志 0 处 Overfull／Underfull／Missing character
make clean    # 清理 PDF 与中间文件
make list     # 查看清单
```

与 `mistakes/Makefile` 同一套可复现规则：`SOURCE_DATE_EPOCH` 取源文件 mtime
固定 PDF 的 `/ID`，`-usepretex` 注入 docinfo 覆盖编译时刻并把 `/CreationDate`
定为源文件日期；源码不变时重编得到逐字节相同的 PDF。
